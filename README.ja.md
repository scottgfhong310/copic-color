# copic-color

> バージョン v1.0｜最終更新 2026-07-29

[繁體中文](README.zh-Hant.md) ｜ [English](README.md) ｜ **日本語**

**COPIC カラーコード → CSS** 対照の閲覧専用 WebApp。単なる色見本の壁ではなく、358 色を
**カラーシステムの三軸**で閲覧します。COPIC の色番号そのものがその三軸だからです——
`BV02` ＝ カラーファミリー `BV` ＋ ブレンディンググループ `0`（彩度 0–9）
＋ インテンシティ `2`（明度 000–9）。ファミリーを選ぶと、その体系がそのまま並びます。

2 ページ目（`sets.html`）が答えるのは実際の購入判断です：**どのセットを買うべきか。**
セットを一つ選ぶ → その色だけ残す → 横に見て他のセットの網羅状況を確認。
ヘッダー行に「基準セットに対する不足色数」が直接出ます。

- **358 色**、17 カラーファミリー、4 製品ライン（Sketch 358／Classic 214／Ciao 180／Copic Ink 358）
- **62 セット**——番号セット（12／24／36／72）とテーマセット（Sea & Sky、Color Fusion、Doodle Kit…）
- **最近似色マッチャー**（`nearestCOPIC`、CIEDE2000）：任意の RGB に最も近いマーカーを提示。
  製品ラインを指定すると、そのラインに実際にある色だけを提案します。
- hex／`rgb()`／`var(--copic-…)`／ユーティリティクラスをコピー、`.css` 全体をエクスポート
- ライト／ダークテーマ、三言語（zh-Hant／en／ja）、バックエンド不要

```bash
npm install && npm start        # → http://localhost:3000/apps/copic-color/
```

## 精度について

hex は公式 COPIC カタログの色見本のベクター塗り値から採取しています。
**カタログ自体が「印刷色は実際のインクの色とは異なる」と明記しています**ので、
画面上の近似値であり公式仕様ではありません。正確な色合わせは実物の色見本をご参照ください。

COPIC はアルコール性の**染料**であり顔料ではありません。メーカーは耐光性等級も
カラーインデックス番号も公表していません。これらの項目が空なのは**データが存在しないため**であり、
採取漏れではありません。

## データ

`public/apps/copic-color/data/copic-*.js` は**ビルド生成物**で、ファミリーの色材ドメイン DB
`db_artcolor`（System of Record）からエクスポートされます。**アプリ自体は DB に接続しません**——
データファイルはバージョン管理下にあり、クローン後は `npm install` だけで動きます。

本アプリは **nodeapp WebApp ファミリー**の一員です。共通規約は
[nodeapp-webapp-family](https://github.com/scottgfhong310/nodeapp-webapp-family) を参照。
